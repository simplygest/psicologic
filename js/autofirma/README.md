# AutoScript de AutoFirma

`autoscript.js` procede del repositorio oficial `ctt-gob-es/clienteafirma`:

- Repositorio: https://github.com/ctt-gob-es/clienteafirma
- Ruta: `afirma-ui-miniapplet-deploy/src/main/webapp/js/autoscript.js`
- Versión indicada por el propio archivo: 1.10.1
- Licencias declaradas por el proyecto: GPL 2+ y EUPL 1.1

Se mantiene una copia local para que el flujo de firma no dependa de un CDN
externo. Antes de actualizarla hay que probar la compatibilidad con las
versiones de AutoFirma soportadas.
