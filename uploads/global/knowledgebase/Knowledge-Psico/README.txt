SimplyGest Therapy - Base de conocimiento clínica v3

Estructura relacional en CSV separados por punto y coma (;).

Tablas:
01_fuentes.csv
02_areas.csv
03_problemas.csv
04_tecnicas.csv
05_tareas.csv
06_problema_tecnica.csv
07_recomendaciones_tareas.csv
08_cuestionarios.csv

Notas importantes:
- Esta base no diagnostica ni sustituye criterio clínico.
- Las tareas son sugerencias para que el profesional seleccione, adapte y supervise.
- Los registros con nivel_riesgo=alto requieren especial prudencia y supervisión clínica directa.
- Las fuentes indican guías o recursos de referencia; no significan que cada frase sea una cita literal.
- Antes de incluir cuestionarios dentro de una app comercial, revisar licencias y condiciones de uso de cada instrumento.
- Para automatización, conviene filtrar por problema_id, nivel_riesgo y prioridad.
